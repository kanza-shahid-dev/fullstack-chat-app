# 💬 Fullstack Chat App  

A real-time chat application built with **MERN Stack**.  
This project allows users to register, log in, and chat in real time with persistent messages.  

🌐 **Live Demo**: [Fullstack Chat App](https://fullstack-chat-app-xiip.onrender.com/)  

---

## ✨ Features  
- 🔐 **Authentication** (JWT & Cookies) – User signup & login  
- 👤 **User Profiles** – Profile info stored in MongoDB  
- 💬 **Real-Time Messaging** – Powered by Socket.io  
- 📂 **Message History** – Stored & retrieved from MongoDB  
- ⚡ **Frontend** – Built with React + Vite for a smooth UI  
- 🎨 **Responsive UI** – Chat from desktop or mobile  
- 🚀 **Deployment** – Hosted on [Render](https://render.com/)  

---

## 🛠️ Tech Stack  

**Frontend:**  
- React (Vite)  
- TailwindCSS  

**Backend:**  
- Node.js + Express  
- Socket.io  
- MongoDB (Mongoose)  
- JWT Authentication  
- dotenv, cookie-parser, cors
